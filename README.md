# cubo-magico
Um cubo mágico 3D interativo desenvolvido com HTML, CSS, JavaScript e Three.js. Pare com o doomscroling, use esse site zen e resolva um cubo 2×2, 3×3 ou 4×4.

## Funcionalidades

* Visualização 3D do cubo mágico
* Rotação livre do cubo através de arraste
* Suporte a interação por toque
* Movimentação individual das camadas
* Embaralhamento automático
* Reversão dos movimentos realizados
* Suporte aos tamanhos:

  * 2×2
  * 3×3
  * 4×4
* Modo claro e escuro
* Interface responsiva
* Animações suaves durante os movimentos
* Renderização 3D utilizando WebGL

## Tecnologias utilizadas

* **HTML5** — estrutura da aplicação
* **CSS3** — interface, responsividade e temas
* **JavaScript** — lógica e interações
* **Three.js** — renderização e manipulação dos objetos 3D
* **WebGL** — processamento gráfico no navegador

O Three.js é carregado diretamente por CDN no projeto.

## Como utilizar

### Girar o cubo

Arraste sobre o fundo da tela para girar o cubo em diferentes direções.

### Girar uma camada

Clique ou toque em uma face do cubo e arraste para movimentar a camada correspondente.

### Embaralhar

Clique no botão **"Embaralhar"** para gerar uma sequência aleatória de movimentos.

### Resolver

O botão **"Resolver"** desfaz os movimentos registrados, retornando o cubo ao estado anterior.

### Alterar o tamanho

Utilize o botão localizado no canto superior da tela para alternar entre cubos **2×2, 3×3 e 4×4**.

### Alterar o tema

O botão de tema permite alternar entre o modo claro e o modo escuro.

## Compatibilidade

O projeto foi desenvolvido para funcionar em navegadores modernos com suporte a:

* HTML5
* JavaScript
* WebGL
* Pointer Events

A interface também possui adaptações para telas menores e dispositivos móveis.

## Objetivo

Este projeto foi desenvolvido como um experimento de **renderização 3D e interação em tempo real no navegador**, explorando manipulação de objetos tridimensionais, animações, eventos de ponteiro e criação de uma interface simples e responsiva.

Este projeto pode ser utilizado e modificado livremente para fins de estudo e experimentação.
